# 루틴 마켓 2주차 진행 작업 보고서 초안

## 전주까지 개발 현황

1. 사용자 모델에 일반회원/트레이너 역할을 정의하고 요청 단계에서 인증 상태/역할/객체 소유권을 검증하며, 장바구니 데이터를 주문으로 변환하고 결제 상태에 따라 다운로드/리뷰 권한을 부여하는 인증/인가 및 구매 상태 전이 로직 구현.

2. 검색어/카테고리/난이도/운동 목적/기간/가격을 SQL 대신 객체 형태로 DB를 처리하는 Django ORM의 조회 조건으로 조합하고, 회원/상품/주문/리뷰를 외래키와 고유 제약조건으로 연결하여 구매 당시 가격과 파일 버전을 보존하는 데이터 처리 로직 구현.

3. Django와 PostgreSQL을 연동하여 개발 환경을 구성하고, 데이터베이스와 업로드 파일을 분리하여 저장하며 실제 서버에서 웹서비스가 실행되도록 배포 환경 구성.

## 금주 작업 사항

1. 메인/상품 상세 페이지를 기준으로 전체 화면에 공통 디자인 시스템을 적용하고 Header/버튼/카드/폼 스타일을 통일하며 PC·모바일 반응형 UI와 간단한 애니메이션 효과 구현.

2. 트레이너 신청과 관리자 승인 절차를 연결하고 승인된 트레이너만 썸네일/XLSX 파일이 포함된 상품을 등록·수정할 수 있도록 역할/승인 상태/상품 소유권을 검증하는 접근 권한 기능 구현.

3. 이메일/닉네임 중복확인과 인증번호 기반 이메일 인증을 적용하고 회원정보 수정, 비밀번호 변경 및 재설정이 가능한 회원 계정 관리 기능 구현.

## 다음주 작업 예정 사항

1. 회원가입/트레이너 신청/상품 등록/구매/리뷰 등 기존 기능의 입력값 검증과 처리 흐름을 점검하고 사용자에게 표시되는 성공/실패 안내 기능 보완.

2. 파일 업로드/가상 결제/XLSX 다운로드 과정에서 오류가 발생해도 데이터가 불완전하게 저장되지 않도록 예외 처리와 복구 로직 보강.

3. 주요 기능을 PC와 모바일 환경에서 반복 테스트하여 발견된 오류를 수정하고, 서버 로그로 오류 원인과 발생 위치를 확인할 수 있는 관리 방식 구성.
