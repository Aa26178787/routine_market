# Routine Market 개발 현황 및 향후 작업

- 최종 갱신일: 2026-09-14
- 현재 단계: MVP 핵심 기능 및 계정·트레이너 프로필 관리 완료, 운영 반영·HTTPS·안정화 및 최종 실기기 검수 전
- 기술 구성: Python 3.14, Django 5.2 LTS, PostgreSQL 대상 설계, Django Template
- 자동 테스트: 최신 코드 기준 테스트 50개 구성. 최종 병합 후 전체 재실행 필요

## 1. 현재 진행 상태 요약

현재 `회원가입 → 트레이너 인증 신청 및 승인 → 상품 등록 → 상품 검색 → 찜 및 장바구니 → 주문 → 가상 결제 → 구매 파일 다운로드 → 리뷰 작성`으로 이어지는 MVP 핵심 흐름이 코드로 연결되어 있다.

로컬 개발 환경은 PostgreSQL 16과 서울 리전의 실제 비공개 S3 저장소를 사용하며, 기존 SQLite와 로컬 파일 저장소로도 전환할 수 있다. 운영 환경은 서울 리전 EC2, 비공개 RDS PostgreSQL 16.13과 비공개 S3를 사용한다. Gunicorn·Nginx 서비스, RDS 마이그레이션, 데모 데이터, 실제 로그인·구매 내역과 S3 이미지 응답까지 검증했다.

## 5. 현재 알려진 제한사항

- 운영 주소는 고정 IP의 HTTP이며 도메인과 HTTPS는 아직 적용하지 않았다.
- 이번 UI/UX 개편은 로컬 코드에만 적용되어 있으며 AWS 운영 사이트에는 아직 배포하지 않았다.
- RDS는 비용을 낮춘 Single-AZ 구성이라 가용영역 장애 자동 전환을 제공하지 않는다.
- 로컬 S3 사용 전 `routine-market` SSO 프로필 로그인이 필요하며 SSO 세션은 만료될 수 있다.
- 로컬 파일 저장 중 데이터베이스 트랜잭션이 실패하면 저장소에 고아 파일이 남을 수 있다.
- 비밀번호 재설정과 회원가입 이메일 인증 로직은 구현했으나 운영용 SMTP 연결 및 실수신 검증은 아직 필요하다.
- 상품 썸네일 또는 루틴 파일 교체 시 사용하지 않는 과거 파일을 정리하는 운영 정책이 없다.
- 실제 결제, 환불 및 판매자 정산은 요구사항에 따라 MVP 범위에서 제외했다.
- 핵심 화면의 모바일 Chromium 검수는 완료했지만 Edge, 실제 기기와 접근성 검수는 남아 있다.
- 서비스 이용약관, 개인정보 처리방침과 운동 프로그램 면책 고지는 검토 전 초안만 있으며 실제 공개 전 법률·운영 검토가 필요하다.

### 12.4 AWS 운영 설정

- 월 10 USD 예산의 80% 도달 시 이메일로 알리는 AWS Budget 구성
- RDS 자동 백업 보존 기간을 1일에서 7일로 확대
- SES SMTP 자격 증명을 Secrets Manager에 저장하고 EC2 역할에 읽기 권한 부여
- SES 발신 이메일 인증 완료, 운영 서버 환경 파일에 SMTP 설정 반영
- SES는 아직 샌드박스 상태이므로 인증되지 않은 수신자에게 발송하려면 프로덕션 액세스 승인이 필요
- 도메인과 DNS가 확정되지 않아 HTTPS 적용은 미완료
