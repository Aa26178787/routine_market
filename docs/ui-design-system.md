# Routine Market UI 디자인 시스템

## 기준과 범위

2026-09-12 제공된 9개 레퍼런스 중 첫 번째 메인/목록 화면을 색상·비율·카드의 기준으로 사용한다. 다른 화면은 레이아웃과 정보 배치만 참고한다. 독립된 상품 상세 이미지는 첨부되지 않아 요청에 명시된 좌측 이미지/우측 구매 정보 구조와 같은 디자인 토큰을 적용했다.

기존 Django 템플릿과 인증/인가, ORM, 장바구니, 주문, 가상 결제, 다운로드, 리뷰, 트레이너 승인 흐름에 연결한다. 이미지에만 있는 소셜 로그인, 쿠폰, 수량 변경, 정산, 커뮤니티, 실제 카드번호 입력은 추가하지 않는다.

## 화면 구성

- 공통 Header: 브랜드 / 검색 / 기존 서비스 메뉴. 키보드 본문 이동 링크 포함.
- 메인: 사진 Hero / 6개 운동 분야 / 최신 루틴 / 리뷰 수 기준 인기 루틴 / 인증 트레이너. 실제 데이터가 없으면 빈 상태 표시.
- 목록: 동일 Hero와 카테고리 / 검색·필터 / 우측 정렬 / 선택 조건 배지 / 상품 그리드.
- 상세: 이미지·상품 정보 좌우 구성 / 큰 가격 / 찜·장바구니·구매 / 소개·트레이너·리뷰 앵커.
- 구매하기: 기존 장바구니 추가 로직을 사용하고 주문 확인으로 이동. 기존 장바구니 상품도 함께 주문 확인에 표시하며, 버튼 클릭만으로 주문이나 결제가 발생하지 않음.
- 로그인/가입: 중앙 카드 / 계정 메뉴 탭 / 로그인 좌측 폼·우측 가입 안내. 트레이너는 기존 가입 후 인증 신청 흐름 유지.
- 트레이너 가입: 로그인 화면의 신청 탭과 시작 카드가 동일한 가입 화면으로 이동 / 가입 완료 후 인증 신청서로 이동 / 일반 가입 탭 선택 시 신청 흐름 해제.
- 트레이너 신청: 전문가 정보와 자격 증빙 섹션 / 우측 절차 안내 / 별도 심사 상태 카드.
- 판매자: 좌측 메뉴 / 상품 관리 테이블 / 등록 폼과 우측 입력 미리보기. 파일 미리보기는 브라우저 내부에서 처리.
- 장바구니/주문: 좌측 상품 / 우측 금액과 주문·가상 결제 버튼.
- 구매 내역: 좌측 메뉴 / 구매일·썸네일·상태·가격·다운로드 / 리뷰 링크.
- 리뷰: 구매 인증 / 별점 라디오 입력 / 내용 / 우측 구매 상품 / 기존 공개 리뷰.
- 관리자: 좌측 관리 메뉴 / 권한에 따른 실데이터 요약 / 승인 대기·최근 주문. 기존 승인/거절 액션과 거절 사유 검증 유지.

## 파일 구조

- templates/base.html: 공통 레이아웃
- templates/shared/: 아이콘, Hero, 카테고리, 필드, 계정/판매자 메뉴

- static/css/admin-market.css: 관리자 전용 테마
- apps/core/templatetags/: 원화 표시 / 권한을 적용한 관리자 요약

## 이미지

상품 이미지는 기존 상품 썸네일을 표시한다. 로컬 데모의 도형 썸네일은 기존 시드 데이터이며 실제 운동 사진으로 임의 교체하지 않았다.

Hero는 imagegen 스킬의 내장 이미지 생성 도구로 제작한 사진을 static/images/hero.png에 저장했다. 프롬프트: “밝은 흰색 현대적인 피트니스 스튜디오, 차가운 푸른 자연광, 오른쪽에 검은 운동복을 입고 팔을 스트레칭하는 성인 동아시아 여성의 측후면, 왼쪽은 HTML 텍스트를 위한 여백, 자연스러운 상업용 사진, 텍스트·로고·UI 없음.”

## 검증 및 미리보기

로컬 전용 SQLite/미디어 디렉터리로 운영 데이터와 분리해 확인했다. PC 1440px와 모바일 390px에서 실제 렌더링·가로 넘침·이미지 로딩·폼 미리보기를 확인했다. 기존 테스트에 공통 화면 렌더링, 관리자 모델별 권한, 원화 표시, 구매 버튼의 기존 주문 확인 연결, 트레이너 가입 탭과 후속 이동 테스트를 추가했으며 전체 36개가 통과했다.

이번 변경은 로컬 구현이며 AWS 운영 사이트 반영과 Git push는 별도다.
