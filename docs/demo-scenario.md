# Routine Market MVP 시연 시나리오

## 1. 시연 전 준비

```powershell
cd C:\Users\qq772\routine_market
.\.venv\Scripts\Activate.ps1
aws sso login --profile routine-market
python manage.py migrate
python manage.py seed_demo --reset
python manage.py runserver
```

브라우저에서 `http://127.0.0.1:8000/`에 접속한다.

### 데모 계정

| 역할 | 이메일 | 확인할 기능 |
|---|---|---|
| 관리자 | `admin@routine-market.local` | 트레이너 신청 승인·거절 |
| 구매자 | `buyer@routine-market.local` | 찜, 장바구니, 구매, 다운로드, 리뷰 |
| 승인 트레이너 | `trainer@routine-market.local` | 상품 등록·수정과 판매 현황 |
| 승인 대기 신청자 | `pending@routine-market.local` | 신청 상태 확인 |

기본 공통 비밀번호는 `RoutineDemo123!`이다. 필요하면 명령 실행 전 `DEMO_PASSWORD` 환경변수로 변경한다. 데모 계정과 비밀번호는 운영 환경에서 사용하지 않는다.

## 2. 비회원 상품 탐색

1. 홈페이지에서 최근 상품 3개와 썸네일이 표시되는지 확인한다.
2. `운동 루틴`에서 검색, 카테고리, 난이도, 기간과 가격 필터를 시연한다.
3. `초보자를 위한 8주 근력 루틴` 상세 화면을 연다.
4. 트레이너 인증 표시, 기간, 주당 횟수, 운동 목적, 가격과 구매 인증 리뷰를 설명한다.
5. 비회원에게는 `로그인 후 구매`가 표시되는지 확인한다.

## 3. 구매자 흐름

1. `buyer@routine-market.local`로 로그인한다.
2. `찜`에서 `하루 20분 홈트와 모빌리티`를 확인한다.
3. `장바구니`에서 `첫 5K 완주 러닝 플랜`을 확인한다.
4. `주문 확인`을 누르고 주문 금액과 상품을 확인한다.
5. 가상 결제를 완료하고 구매 내역으로 이동한다.
6. 구매 파일 다운로드 버튼과 다운로드 권한 보호 방식을 설명한다.
7. 이미 구매한 `초보자를 위한 8주 근력 루틴`의 5점 리뷰를 확인한다.

시연을 반복하려면 서버를 중지한 뒤 `python manage.py seed_demo --reset`을 다시 실행한다.

## 4. 트레이너 흐름

1. `trainer@routine-market.local`로 로그인한다.
2. `판매 관리`에서 공개 상품 3개와 판매·평점 집계를 확인한다.
3. 상품 등록 화면에서 썸네일과 XLSX 운동 루틴 검증 규칙을 설명한다.
4. 상품 수정과 판매 중지 기능을 시연한다면 종료 후 데모 데이터를 초기화한다.

## 5. 관리자 흐름

1. `admin@routine-market.local`로 로그인하고 관리자 화면으로 이동한다.
2. 트레이너 인증 신청에서 `승인대기코치`의 심사 대기 신청을 선택한다.
3. `선택한 심사 대기 신청 거절` 액션을 선택한다.
4. 거절 사유 입력 화면과 빈 사유 차단을 설명한다.
5. 시연에서는 취소하거나, 실제 거절 후 `seed_demo --reset`으로 신청 상태를 복구한다.
6. 상품, 주문, 리뷰와 다운로드 로그를 관리자 화면에서 조회한다.

## 6. 보안 설명 포인트

- DB 비밀번호는 Git이 아니라 로컬 `pgpass.conf`에서 관리한다.
- AWS는 장기 액세스 키 대신 IAM Identity Center SSO를 사용한다.
- S3 버킷은 퍼블릭 접근이 모두 차단되어 있다.
- 구매 권한을 서버에서 검사한 뒤 300초짜리 서명 URL을 발급한다.
- 주문은 구매 당시 가격과 파일 버전을 보존한다.
- 트레이너 증빙 원본은 일반 사용자에게 공개하지 않는다.
