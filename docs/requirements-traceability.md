# Routine Market 요구사항 구현 추적표

- 기준일: 2026-09-14
- 기준 문서: `docs/requirements-specification.md` 1.0
- 상태 정의: **완료**(구현 및 직접 관련 테스트 존재), **부분**(핵심 구현은 있으나 일부 검증·운영 조건 미완료), **미완료**

이 문서는 코드와 자동 테스트를 기준으로 작성했다. 운영 인프라나 실기기 확인이 필요한 항목은 코드가 있어도 `부분`으로 표시했다.

## 제출 전 확인 체크리스트

- 최종 병합 상태에서 `check`, 마이그레이션 누락 검사, 전체 테스트 결과를 기록한다.
- Chrome·Edge 및 실제 모바일에서 가입→구매→다운로드→리뷰 흐름을 수행한다.
- 키보드 포커스, 레이블, 대체 텍스트, 명암 대비를 확인한다.
- 운영 SMTP, HTTPS, 백업·복원, 비용 알림과 장애 로그를 확인한다.
- 법적 문서의 대괄호 자리표시자를 실제 사업 정보로 교체하고 전문가 검토를 받는다.
